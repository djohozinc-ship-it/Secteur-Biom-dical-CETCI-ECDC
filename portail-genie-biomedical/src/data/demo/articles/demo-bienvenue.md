Ceci est un **article de démonstration**.

Pour publier une actualité, créez un fichier `.md` dans `src/data/articles/` avec cet en-tête :

- `title` : le titre
- `date` : au format AAAA-MM-JJ
- `category` : la catégorie
- `summary` : le résumé affiché sur la carte

## Écrire le contenu

Le texte s'écrit en Markdown : titres, **gras**, *italique*, listes et liens.
